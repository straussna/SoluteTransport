SoluteTransport

A .NET library that simulates one-dimensional solute advection and dispersion in stream reaches, with transient storage and sediment sorption, solved by a Crank-Nicolson finite-difference scheme. This documentation collects the papers behind the model.

Start here

two commands

The example console app runs one simulation; the tests check the solver.

dotnet run --project "C:\source\repos\SoluteTransport\src\SoluteTransport.Example\SoluteTransport.Example.csproj"
dotnet test "C:\source\repos\SoluteTransport\tests\SoluteTransport.Tests\SoluteTransport.Tests.csproj"
